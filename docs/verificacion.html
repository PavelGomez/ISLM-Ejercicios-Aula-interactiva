Especificación de clases

Oferta real M/P; demanda real Mᵈ = d₁Y − d₂i = kY − hi, con d₁ = k > 0 y d₂ = h > 0. El equilibrio exige M/P = Mᵈ. Consumo: C = c₀ + c₁(Y − T) con impuestos fijos o C = c₀ + c₁(Y − tY) con proporcionales. Inversión: I = b₀ + b₁Y − b₂i, con b₀, b₁ y b₂ mayores que cero. Se calibró M = 800, P = 2, M/P = 400. Los cuatro equilibrios base y las respuestas a los shocks permanecen iguales. Pantallas, locución, documentos y exportaciones comparten estas convenciones.

  • No se localizaron los tres archivos específicos de work/islm_chile citados en el encargo. La memoria identifica los antecedentes efectivamente revisados y evita atribuir decisiones a los ausentes.
  • Publicación estática en GitHub Pages, con código en GitHub y paquete sin conexión. La comprobación de la publicación se registra separadamente de las pruebas locales.
Límite económico: las cifras son calibraciones didácticas. El modelo cerrado y con precios dados no permite inferir resultados empíricos para Chile, bienestar, inflación, deuda ni una trayectoria temporal de ajuste.
